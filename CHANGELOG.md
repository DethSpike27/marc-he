## [1.0.0] - 2024-12-19

### 🎉 Version initiale

#### ✨ Ajouté
- **Programme de 8 semaines** avec progression 15→20→25→30 min
- **Sélection des jours** : 3 jours personnalisables par semaine
- **Checkboxes de suivi** : Marque tes séances complétées
- **Mode maintien** : Continue indéfiniment après les 24 premières séances
- **Timer Aller/Retour** avec alerte mi-temps pour faire demi-tour
- **Indicateur de phase** : ALLER (bleu) / RETOUR (violet)
- **Barre de progression** visuelle sur le timer
- **Calendrier historique** avec navigation mensuelle
- **Graphique statistiques** : 30 derniers jours (Chart.js)
- **Métriques clés** : Total séances, minutes, calories
- **Système de badges** : 9 badges à débloquer
- **Profil utilisateur** : Nom, poids (lb/kg), taille (cm/pieds), âge, objectif
- **Calculs automatiques** : IMC et calories/minute personnalisées
- **Notes par séance** : Enregistre tes ressentis
- **Synchronisation Firebase** : Google Auth + Realtime Database
- **Merge intelligent** : Combine données locales et cloud
- **Multi-appareils** : Sync automatique entre tous tes devices
- **Mode sombre/clair** : Toggle avec sauvegarde
- **Design responsive** : Mobile, tablette, desktop
- **Règles d'or** : Test de la parole, règle de la douleur, choix du terrain
- **Routine anti-bureau** : Échauffement 2 minutes
- **Export JSON** : Sauvegarde locale de toutes les données
- **Notifications** : Alertes sonores et popup pour le timer
- **LocalStorage** : Sauvegarde automatique locale
- **Bouton réinitialisation** : Recommencer au niveau débutant

#### 🎨 Design
- Gradient violet/indigo élégant
- Cartes en verre givré (glass effect)
- Animations fluides
- Tailwind CSS
- Icons emoji intégrés
- Checkboxes personnalisées
- Accordéons interactifs

#### 🔧 Technique
- HTML5 + CSS3 + JavaScript Vanilla
- Firebase SDK 10.12.0
- Chart.js 4.x
- Aucune compilation requise
- Fonctionne hors-ligne (avec localStorage)
- Progressive Web App ready
